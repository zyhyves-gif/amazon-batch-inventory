# 亚马逊批次进销存

这是从 Open Design 原型升级而来的真实数据版，适合目前 2 人协作使用。三家公司共用国内库存，出库时再选择业务公司；同一 SKU 可以按工厂、供应商、入库日期和批次追踪，出库与销售按 FIFO 自动扣减。

## 当前可用功能

- 三种角色：管理员、库存操作员、财务
- 库存操作员可查看全部经营、成本和利润信息
- SKU、公司、工厂、供应商档案
- 批次入库与国内仓共享库存
- FIFO 出库及来源批次追踪
- 国内仓、运输中、FBA 接收中、FBA 可售节点流转
- 销售、亚马逊费用、净收入和其他经营费用
- 实时库存、FIFO 成本和经营利润
- 按日期导出多工作表 Excel
- 历史数据整理空白模板

## 本机测试

电脑需要安装 Node.js 22 或更高版本。第一次打开项目时：

```text
npm install
npm run dev
```

浏览器打开 `http://localhost:3000`。本机测试会自动使用“本地管理员”身份，数据保存在项目自己的本地测试数据库中。

停止测试时，在命令窗口按 `Ctrl + C`。

## 正式使用顺序

1. 管理员先在“用户与设置”中添加同事邮箱和角色。
2. 在“工厂 / 供应商”中补齐第三家公司、店铺、工厂和供应商。
3. 在“商品管理”中建立 SKU。
4. 从“入库管理”录入第一批真实库存。
5. 出库后按物流进度更新库存节点。
6. 管理员或财务录入销售、回款口径收入和其他经营费用。
7. 从“报表导出”下载 Excel 汇报。

## 数据口径

- 金额在数据库中按“分”保存，页面和 Excel 按人民币“元”显示。
- 国内库存为三家公司共享库存，不在入库时拆公司。
- 出库从国内仓可用库存中按最早入库日期 FIFO 分配。
- 销售从 FBA 可售库存中按 FIFO 结转采购成本。
- 当前经营利润 = 净销售收入 - FIFO 采购成本 - 其他经营费用。
- 历史老库存来源不明时，建议建立 `INITIAL-UNKNOWN` 期初批次后再导入。
